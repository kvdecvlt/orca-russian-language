# Contributing

Правки перевода приветствуются. Весь текст лежит в `locales/ru-RU.json`;
`orca-plugin.json` менять нужно только для версии или метаданных.

## Правила перевода

- Переводи только **значения**, ключи не трогай.
- Сохраняй плейсхолдеры как есть: `{{value0}}`, `{{value1}}` — включая порядок и цифры.
- Не переводи и не меняй: код, команды, флаги, пути, URL, расширения файлов,
  имена клавиш (`Tab`, `Esc`, `Mod+Alt+T`), названия IDE, провайдеров и моделей.
- Оставляй на английском: `Orca`, `worktree`, `workspace`, `repo`, `branch`,
  `commit`, `diff`, `merge`, `PR`, `MR`, `issue`, `agent`, `terminal`, `prompt`,
  `token`, `SSH`, `WSL`, `VM`, `Docker`, `CI`, `GitHub`, `GitLab`, `Linear`, `Slack`.
- Названия языков в селекторе — эндонимы: `English`, `中文（简体）`, `한국어`,
  `日本語`, `Español`, `Français`; переводится только `System` → «Системный».
- Естественный, короткий UI-русский. Кнопки — императив («Сохранить»), настройки —
  существительными.

## Лимиты

Каталог обязан проходить валидатор `scripts/validate-language-pack.mjs`:

- ≤ 20 000 записей, глубина ≤ 16, значение ≤ 8192 символа;
- ключи без точек и управляющих символов, длиной 1..128;
- нельзя переопределять защищённые строки управления плагинами
  (`auto.components.settings.*plugin*`) — Orca их плагам менять запрещает.

## Проверка

```sh
node scripts/validate-language-pack.mjs
```

## Процесс

1. Форк → ветка.
2. Правки.
3. `node scripts/validate-language-pack.mjs` локально.
4. Pull request в `main`. CI (`validate`) должен пройти.
